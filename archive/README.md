# Archive

Older versions, test sketches and course material from building the robot. None of this is used by the final robot. I kept it here for reference.

| File | What it was |
|---|---|
| `ARDUINO_PID_Controller_Test.ino`, `Combined` | Earlier versions of the balance controller (first PID gains, before Bluetooth) |
| `ESP32_Joystick_Directions.ino`, `ESP32_Joystick_LCD.ino` | First pieces of the remote: reading the joystick, then adding the LCD |
| `arduino_flutter_ble_receiver.ino` | Experiment with driving the robot from a phone app over Bluetooth |
| `ARDUINO_Ultrasonic_Sensor.ino` | First ultrasonic sensor and beeper test (blocking version) |
| `PWM.ino`, `variablePWM_acc_test.ino` | Motor and PWM tests |
| `fast_decay_PWM.ino`, `slow_decay_PWM.ino` | Comparing the two motor driver decay modes |
| `task2`–`task4` (`.ino` + `.py`) | Course tasks: tilt from the accelerometer, then the gyroscope, then both combined, each plotted live in Python |
| `angle_measurement_simulation_v1.m` | First version of the MATLAB tilt simulation |
| `Angle sensing with Arduino nano BLE sense IMU.pdf` | The course handout for the angle-sensing assignment |
